# Atom Material Icons

Original SVG assets from https://github.com/mallowigi/iconGenerator at commit
`ed98d2327eb9e84e845a828652b08eb4c7f26b09`, the generator submodule used by
https://github.com/AtomMaterialUI/a-file-icon-vscode.

MIT license, copyright Elior Boukhobza; see LICENSE. SVG files are unchanged.
Only the file/folder subset used by this TypeScript-oriented viewer is bundled.
Filename associations live in src/icons.ts; native extension settings and product icons are not included.
