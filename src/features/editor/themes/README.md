# One Dark

Source: https://github.com/one-dark/vscode-one-dark-theme (ISC).
`one-dark-editor.ts` and `one-dark-textmate.ts` preserve the upstream UI colors and standard token scopes from generator/theme/editor.ts and theme.ts. The standard palette is in one-dark-palette.ts; license in ONE-DARK-LICENSE.

Shiki supplies TextMate grammars for Monaco. TypeScript, TSX, JavaScript and JSX use distinct language IDs. UI overrides keep menus opaque and preserve the viewer's minimal selection styling. WebStorm semantic analysis and IDE-specific coloring are not replicated.
